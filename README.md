# Hotel_Booking_Data_Analysis
Project Overview

An end-to-end exploratory data analysis project using Python, Pandas, and Seaborn to examine hotel booking trends, cancellation behavior, pricing patterns, and customer segments.

The goal is to transform raw booking data into meaningful insights that can support data-driven decisions in the hospitality industry.

Tools & Technologies

* Python
* Pandas
* Seaborn
* Google Colab

Project Workflow

1. Data Exploration
2. Data Cleaning & Validation
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights & Recommendations

Key Findings

* Analyzed approximately 119,000 hotel booking records.
* The overall booking cancellation rate was approximately 37.08%.
* City Hotel had a higher cancellation rate than Resort Hotel.
* August recorded the highest booking volume (13,861), while January recorded the lowest (5,921) across the available data.

Note: The dataset contains partial years, so monthly booking totals should not be interpreted as definitive annual seasonality.

Business Recommendations

* Improve booking confirmation and pre-arrival communication to help manage cancellations.
* Investigate cancellation patterns at City Hotel.
* Use booking demand patterns to support staffing and operational planning.
* Evaluate pricing differences across hotel types and booking lead times.
* Monitor customer segments with high cancellation rates.

Project Deliverable

A Jupyter Notebook containing data cleaning, exploratory analysis, visualizations, and business findings.

Future Improvements

* Analyze seasonality using comparable full-year periods.
* Develop an interactive Power BI dashboard.
* Explore predictive modeling for booking cancellations.
